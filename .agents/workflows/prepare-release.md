# Workflow: Prepare Release

Prepare release inspection without performing any automated release actions.

## Rules & Steps

1. Check `custom_components/adaptive_areas/manifest.json` and `hacs.json` for current version info.
2. Review unreleased changes and documentation.
3. Ensure a changelog is provided/updated for the pre-release or release.
4. **STRICT REQUIREMENT:** Do NOT create versions, tags, commits, releases, or PRs without explicit approval and instruction from Andreas.
