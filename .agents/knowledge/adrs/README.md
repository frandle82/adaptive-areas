# Architectural Decision Records (ADRs)

Architekturentscheidungen für `adaptive-areas` werden hier als durchnummerierte Markdown-Dateien nach folgendem Namensschema hinterlegt:

`NNN-<titel>.md` (z. B. `001-sensor-aggregation-strategy.md`)

## Struktur eines ADRs
- **Status:** Entwurf / Angenommen / Abgelehnt / Veraltet
- **Kontext:** Problemstellung und Anforderungen
- **Entscheidung:** Was wurde entschieden und warum?
- **Konsequenzen:** Auswirkungen auf Architektur, Performance, Breaking Changes, Tests
